# 🍳 Recipe Generator ( Chef 4U) 

A smart web application that suggests recipes based on ingredients you have at home. Powered by AI using Groq's API.

## ✨ Features

- 🥘 **Ingredient-Based Recipe Suggestions** - Input your available ingredients and get personalized recipe recommendations
- 🤖 **AI-Powered** - Uses advanced AI models to generate creative recipes
- 🎨 **Beautiful Formatting** - Recipes are formatted with markdown, emojis, and clear structure
- ⚡ **Fast & Responsive** - Built with modern web technologies for smooth performance
- 🔒 **Secure API Calls** - Backend handles all API keys safely

## 🛠️ Tech Stack

### Frontend
- **React** - UI library
- **Vite** - Build tool & dev server
- **CSS** - Styling
- **Tailwind** - Styling
- **JavaScript** - Logic

### Backend
- **Vercel Functions** - Serverless API
- **JavaScript** - Backend logic
- **Groq SDK** - AI provider

### AI
- **Groq API** - AI provider

### Deployment & Version Control
- **Vercel** - Hosting (frontend + backend)
- **GitHub** - Version control

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn
- Groq API key
